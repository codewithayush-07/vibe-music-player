# Vibe Music Player

Vibe Music Player is a web-based music player I built using HTML, CSS,
and JavaScript. I wanted to create a simple music player with a modern
interface and useful controls while practising JavaScript and working
with APIs.

## Features

-   Play and pause audio
-   Skip to the next or previous track
-   View track information in the player
-   Add songs to favourites and view them in the Favourites section
-   Responsive layout for different screen sizes
-   JavaScript-based interactions and API integration

> Note: Available tracks and playback depend on the audio source or API
> configured in the project. If the API is unavailable, some features
> may not load as expected.

## Built With

-   HTML5
-   CSS3
-   JavaScript
-   Fetch API (for loading data from an external source)

## Run the Project

1.  Download or clone this repository.
2.  Open the project folder in VS Code or another editor.
3.  If the project uses separate files, keep `index.html`, `style.css`,
    and `script.js` in the same folder (or preserve the paths used in
    the HTML).
4.  Run `index.html` using the VS Code Live Server extension.

Some browsers restrict API requests when a page is opened directly with
`file://`, so using Live Server is recommended.
